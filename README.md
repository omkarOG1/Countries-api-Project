# 🌍 Countries Search App

This is a frontend project where I built a countries search application using a public API.  
The main focus was to practice API integration, DOM manipulation, and improve UI/UX.

## 🚀 Features

- Search countries by name  
- Filter countries by region  
- View detailed country information (flag, population, region, capital, etc.)  
- Dark mode toggle 🌙  
- Dark mode preference saved using localStorage  
- Responsive design (mobile + desktop)

## 🛠️ Tech Used

- HTML  
- CSS  
- JavaScript  
- REST Countries API  

## 🔗 Live Demo

https://countries-search-og.netlify.app/

## 📚 What I Learned

- Fetching and handling API data using `fetch` and async/await  
- Filtering and searching data dynamically  
- Managing UI state (dark mode) with localStorage  
- Improving responsive design using CSS  

## ⚡ Challenges

- Handling large API data and filtering efficiently  
- Maintaining UI consistency between light and dark modes  
- Managing state without any framework  

## 📌 Future Improvements

- Add loading spinner while fetching data  
- Improve UI design and animations  
- Optimize performance for large datasets
